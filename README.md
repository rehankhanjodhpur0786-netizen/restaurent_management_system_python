#  Restaurant Management System (Python)

This is a simple Restaurant Management System built using Python.

---

##  Features
- User login system
- Menu management
- Order processing
- Bill generation
- Table booking system
- Data stored using JSON files

---

##  Concepts Used
- Object-Oriented Programming (OOP)
  - Classes and Objects
  - Constructors (__init__ method)
- Modular Programming (using folders and __init__.py)
- File Handling
- JSON Data Storage

---

##  Project Design

The project follows a modular structure where different functionalities are separated into folders:

- auth → handles user authentication  
- menu → manages menu items  
- order → processes orders  
- billing → generates bills  
- database → handles data storage  

---

##  Data Storage

All data such as users, orders, and menu items are stored in JSON files:

- users.json → stores user details  
- orders.json → stores order history  
- menu.json → stores menu items
